Theme:
- Dark: #080B11 / #131C2E / #0E1422 / cyan #00F0FF
- Light: #F1F5F9 / #FFFFFF / #F8FAFC / blue #0284C7

- No external font files are required.

## Before publishing
Replace every instance of:

REPLACE_WITH_YOUR_SUPPORT_EMAIL

with your real support email.

## GitHub Pages
1. Create a public repository in the GitHub account `Alva121`, for example `apps` or `privacy`.
2. Upload the contents of this ZIP to the repository root.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).

Example URLs:
- https://Alva121.github.io/apps/
- https://Alva121.github.io/apps/geophoto/privacy-policy.html
- https://Alva121.github.io/apps/geovelocity/privacy-policy.html

Note: GeoPhoto policy text is populated from the current GeoPhoto audit.
GeoVelocity currently contains a themed policy shell and should be finalized after a release-data audit.
